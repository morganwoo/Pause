# Pause. • Think Before You Buy

> A behavioral finance web application that acts as a "financial placebo," giving you the dopamine rush of online checkout while locking impulse purchases in a 14-day cooldown vault.

---

## 📌 Project Overview

Online shopping has eliminated all friction with one-click checkouts and digital wallets, leading to impulsive spending driven by an immediate craving for dopamine. Traditional budgeting tools rely on guilt or restrictive site blockers, which consistently fail against human psychology. 

**Pause.** is a psychological circuit breaker. Instead of preventing you from shopping, it lets you "pre-order" the item, rate your desire level, and experience an authentic order confirmation receipt—giving your brain the satisfaction of checkout without touching your bank account. Items enter an interactive 14-day cooldown vault, allowing emotional urgency to fade so you can make rational, regret-free financial decisions.

---

## 🛠️ Tech Stack

* **Frontend:** Vanilla HTML5, Modern CSS3 (Dark-mode Glassmorphism), JavaScript (ES6+)
* **Data Visualization & UX:** Scalable Vector Graphics (SVG) Donut Charts
* **Backend:** Java, Supabase, Railway, PostgreSQL, Spring Boot
* **Collaboration & Tools:** Git, GitHub, and Generative AI (utilized for pair-programming, component scaffolding, and CSS styling)

---

## ✨ Key Features

* **Simulated Checkout (The Dopamine Hit):** Pre-order any item with custom links, prices, personal justifications, and an impulse intensity rating (scale 1–10). Receives an authentic order confirmation with a unique reference ID.
* **7-Day Cooldown Vault:** Items are displayed in a clean 3-column grid with live countdown timers ticking down **Days, Hours, Minutes, and Seconds** in real time.
* **Discipline Ratio Analytics:** An interactive SVG donut chart that measures financial self-control by calculating the live ratio of stopped purchases versus completed buys, alongside average impulse scores.
* **Positive Financial Reinforcement:** Choosing "Don't Buy" once the timer expires launches a confetti celebration and immediately updates the sticky header HUD with your lifetime **Potential Spending Avoided**.
* **Hackathon Demo Shortcut:** Built-in `⚡ Skip Timer (Demo)` controls to fast-forward any cooldown to 0 days for immediate demonstration.
* **User Profile & Budgeting:** Dedicated profile dashboard allowing users to set monthly shopping budgets, update account credentials, and track personal savings milestones.
