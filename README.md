Impulse spending prevention
Purpose:
People who regret spending money they can’t spare
Website one goes to when wanting to buy an item
Add the item
  Name, price, photo, reason for wanting it
  Textbook to paste in link of item and it can auto fill
    Website AI scans content of the link, takes price + picture and displays it on screen
Countdown card per item showing days left
Desire chart over time per item
Each item shows price
“Pre-order Now” button to fulfill desire of purchasing without officially buying
Default countdown of 2 weeks occur, but can be manually set longer
Total Saved is displayed, once an order is declined it will be added to the total saved
If user does complete the 2 weeks, website gives back the original link to purchase
Shopping budget is displayed, can show price against budget for each item
Eg. This is 40% of your monthly budget
